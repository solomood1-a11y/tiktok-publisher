سياسة خصوصية TikTok Publisher

آخر تحديث: 21 سبتمبر 2026

1. البيانات التي نعالجها

قد نعالج بيانات الحساب الأساسية التي توفرها TikTok بعد موافقة المستخدم، مثل معرّف الحساب واسم العرض، بالإضافة إلى بيانات المقاطع التي يختار المستخدم تجهيزها أو نشرها.

2. طريقة استخدام البيانات

تُستخدم البيانات لربط حساب المستخدم، تجهيز المقاطع، تنفيذ النشر الذي يطلبه المستخدم، وإظهار حالة العملية. لا نبيع البيانات ولا نستخدمها للإعلانات المخصصة.

3. TikTok وOAuth

يتم التفويض عبر واجهة TikTok الرسمية. لا نطلب كلمة مرور TikTok ولا نخزنها. قد تعالج TikTok البيانات وفقًا لسياسة الخصوصية الخاصة بها.

4. التخزين والأمان

نحتفظ بالبيانات فقط طوال المدة اللازمة لتقديم الخدمة ونستخدم وسائل معقولة لحمايتها. لا توجد وسيلة نقل أو تخزين مضمونة بنسبة 100%.

5. مشاركة البيانات

لا نشارك البيانات مع أطراف ثالثة إلا عند الضرورة لتقديم الخدمة أو إذا طلب المستخدم النشر عبر TikTok أو أوجب القانون ذلك.

6. حذف البيانات وإلغاء التفويض

يمكن للمستخدم إلغاء التفويض من إعدادات TikTok أو طلب حذف بياناته عبر صفحة GitHub الخاصة بصاحب التطبيق. سنعالج طلب الحذف خلال مدة معقولة.

7. الأطفال

الخدمة ليست موجهة للأطفال دون السن المسموح به قانونًا، ولا نجمع بياناتهم عن قصد.

8. التواصل

للاستفسارات وطلبات الخصوصية: صفحة GitHub الخاصة بصاحب التطبيق.

9. تغييرات السياسة

قد نحدّث هذه السياسة عند الحاجة، وسننشر النسخة الجديدة على هذه الصفحة مع تحديث تاريخ المراجعة.
