شروط استخدام TikTok Publisher

آخر تحديث: 21 سبتمبر 2026

1. وصف الخدمة

يتيح TikTok Publisher للمستخدم تجهيز مقاطع الفيديو وجدولتها ونشرها على حسابه في TikTok بعد منحه التفويض الرسمي.

2. حقوق المحتوى

يقر المستخدم بأنه يملك حقوق كل محتوى يرفعه أو لديه إذن صالح لاستخدامه وإعادة تحريره ونشره. المستخدم مسؤول عن أي مطالبات تتعلق بحقوق النشر أو العلامات التجارية أو الخصوصية.

3. ربط TikTok

يتم ربط الحساب من خلال واجهة TikTok الرسمية وتفويض OAuth. لا يطلب التطبيق كلمة مرور TikTok ولا يخزنها.

4. النشر والجدولة

يستطيع المستخدم إلغاء النشر أو الجدولة في أي وقت. لا يضمن التطبيق الوصول أو الانتشار أو عدد المشاهدات، وقد ترفض TikTok بعض المنشورات وفقًا لسياساتها.

5. السلوك الممنوع

يحظر استخدام الخدمة لنشر محتوى غير قانوني أو مضلل أو ينتهك حقوق الآخرين أو يخالف إرشادات مجتمع TikTok.

6. إلغاء الربط وحذف البيانات

يمكن للمستخدم إلغاء التفويض من إعدادات TikTok، كما يمكنه طلب حذف أي بيانات مرتبطة بالخدمة عبر صفحة GitHub الخاصة بصاحب التطبيق.

7. إخلاء المسؤولية

تُقدم الخدمة كما هي دون ضمانات بشأن التوفر أو النتائج. هذا التطبيق مستقل وغير تابع لشركة TikTok أو ByteDance.

8. التواصل

للتواصل وطلبات حذف البيانات: صفحة GitHub الخاصة بصاحب التطبيق.
